How this site is built

Design: a restrained black/gold palette, one accent color, and motion reserved for hover and step transitions rather than scattered page-load animation.

Front end: a single static HTML/CSS/JS file — no framework build step required, so it can be hosted anywhere.

Security note: the admin panel on this demo uses a client-side PIN for demonstration only. A real deployment needs server-side authentication (hashed credentials, rate-limiting, session tokens) and a real database — see the note in the admin panel for what to add.

Data: by default, orders are kept in memory for this browser session only. Once a Firebase project is connected (see the code comments), orders sync live across every device instead.
